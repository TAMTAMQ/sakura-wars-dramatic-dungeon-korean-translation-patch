# 대사 표현 검토 — 2026-11-04

사용자가 지적한 3장 도입의 에리카 대사와 함께 다른 장의 감탄사·당황
표현을 검토했다. 3장 도입 225개 레코드와 전 장에서 추린 표현 후보의
앞뒤 대사를 읽고, 총 47개 레코드를 수정했다. 게임 전체 대사의 재검수를
완료했다는 뜻은 아니다.

- `꺄악, 어떡하죠……` → `어머나, 어떡하죠……`:
  의식을 잃은 오오가미를 걱정하는 장면의 당황 표현.
- `죽으면 싫어요……` → `죽지 마세요……`:
  의식을 되찾기를 바라는 부탁.
- 도입부의 아침 인사와 이어지는 핀잔, 존칭을 함께 맞췄다.
- `와햐앗`·`으햐앗` 등의 음역을 문맥에 맞는 한국어 감탄사로 바꿨다.
- `エンジン全開`의 `엔진 전개`를 `전력으로 갑니다`로 수정했다.
- `またどうぞ、ごひいきに！`는 `앞으로도 자주 찾아주세요!`로 수정했다.

거미·추격·공격 장면의 실제 비명, 제미니의 연기, 플럼의 고유 말버릇과
고정 구호는 보존했다. 원문·원본 바이트·위치 정보는 바꾸지 않았다.
번역의 `cross_review_required` 상태는 유지한다.

검사 범위는 수정 47곳의 최종 ROM 문자열 바이트 일치, 원문 보존,
원문 파일을 기준으로 한 표시 폭 참고 검사와 전체 빌드이다.
표시 폭 참고 검사는 각 장면의 실기 화면 검수를 대신하지 않는다.
상세 전후 문맥 판단과 검사 근거는 로컬 작업 폴더
`work/dialogue-expression-review/`에 보관한다.

이번 빌드에서 드러난 문자열 재배치 오류도 수정했다. 재귀 이동 중인
문자열의 이전 슬롯은 이후 통째로 지워지므로 그 꼬리 공간을 다른
문자열의 목적지로 할당하지 않는다. 누락이나 재배치 검증 오류가 있으면
주 파이프라인은 최종 ROM을 쓰기 전에 중단한다.
