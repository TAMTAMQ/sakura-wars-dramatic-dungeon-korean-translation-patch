# 전체 번역 검수 기록 (ChatGPT)

- 대상: `assets/translation/segments/*.json`
- 검수 원칙: 일본어 원문과 현재 한국어 번역을 직접 대조하고, 의미 오류/누락/반전/명백한 오역만 수정한다.
- 동시 작업 대응: 각 파일 검수 시작/종료 시 SHA-256을 비교한다. 검수 도중 해시가 바뀐 파일은 수정하지 않고 보류한 뒤, 다른 파일을 먼저 검수하고 최신본으로 해당 파일을 처음부터 다시 검수한다.
- 로그 형식: 파일 / ID / 일본어 원문 / 기존 번역 / 신규 번역 / 수정 사유
