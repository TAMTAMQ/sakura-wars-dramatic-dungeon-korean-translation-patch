# 드라마틱 던전 사쿠라 대전 \~그대가 있기에\~ 한글패치

Nintendo DS용 《ドラマチックダンジョン サクラ大戦 ～君あるがため～》
일본판을 한국어로 즐길 수 있게 만든 비공식 한글패치입니다.

> 현재 상태: v0.2 배포
>
> 게임 내 모든 문자열의 번역과 검수를 마쳤습니다. GitHub Releases에서
> 패치 파일을 받을 수 있습니다.

## 지원 원본

반드시 아래 조건과 일치하는 무수정 일본판 ROM을 사용해야 합니다.

| 항목 | 값 |
|---|---|
| 플랫폼 | Nintendo DS |
| 게임 코드 | `YS9J` |
| 리비전 | `0` |
| ROM 크기 | `67,108,864 bytes` |
| SHA-256 | `e6cafe64437080bf5474fa7f9cfec6568b2af7626b65c3ab0d27d30308cec7c4` |

다른 지역판, 변조된 ROM 또는 이미 다른 패치가 적용된 ROM은 지원하지 않습니다.

## 패치 적용 방법

1. GitHub Releases에서 `dramatic-dungeon-kr.xdelta`를 받습니다.
2. 위 해시와 일치하는 일본판 원본 ROM을 준비합니다.
3. xdelta 패처에서 원본 ROM과 받은 `.xdelta` 파일을 선택합니다.
4. 생성된 한글판 ROM을 실기 또는 Nintendo DS 에뮬레이터에서 실행합니다.

명령줄용 `xdelta3`를 사용하는 경우에는 다음과 같이 적용할 수 있습니다.

```text
xdelta3 -d -s "일본판 원본.nds" dramatic-dungeon-kr.xdelta "한글판.nds"
```

적용 전에는 원본 ROM과 저장 데이터를 별도로 백업해 두는 것을 권장합니다.

패치를 잘못된 ROM에 적용하면 조용히 깨지지 않고 오류로 중단되므로, 위
SHA-256과 일치하는 원본을 준비했는지 먼저 확인해 주세요.

### 적용 결과 확인

패치를 올바르게 적용했다면 결과 ROM이 아래와 같아야 합니다.

| 항목 | 값 |
|---|---|
| 패치 파일 SHA-256 | `afc11701f3af5082db625d574507b1a4e00b442cee41fa267ac3564262d2544e` |
| 한글판 ROM 크기 | `65,209,404 bytes` |
| 한글판 ROM SHA-256 | `0222f53da7e02645ac71626ecd9140675a0f579c2faaafbb6c5dd9c5a7f3c7c4` |

## 번역 범위

- 관리 중인 문자열 23,549개 가운데 번역 대상 22,804개 전부 적용
  (나머지는 여백 줄처럼 번역할 내용이 없는 레코드)
- 물마루 기반 한글 글꼴 적용 (전용 글리프 1,185자)
- 메뉴, 대사, 도움말, 아이템·마물 도감 전체 번역
- 이미지 속 일본어 183건 교체 (교체하지 않은 이미지는 원본 그대로)
- 타이틀 배너를 한국어로 교체

번역문은 전 파일을 원문과 한 줄씩 대조해 검수했습니다. 등장인물 말투와
호칭, 용어 표기를 통일했고, 화면 밖으로 잘리는 줄이 없도록 파일마다 원문
최장 줄을 기준으로 표시 폭을 맞췄습니다.

한글이 원래 문자열 자리보다 길어진 385건은 ROM 내 빈 공간으로 재배치했으며,
재배치가 다른 문자열을 건드리지 않았음을 검증했습니다.

## 알려진 제한

- LIPS 단어 맞추기 중 「ポーズ」 문제는 타일이 `포ー즈`로 표시됩니다. 정답
  타일 수가 원문 글자 수에 고정되어 있어 `포즈` 두 글자로 줄일 수 없습니다.
- 실기·에뮬레이터 완주 검증은 계속 진행 중입니다. 진행 불가 문제를 발견하면
  아래 안내에 따라 제보해 주세요.

## 저장소에 포함된 내용

- `assets/translation/`: 한국어 번역 데이터
- `assets/fonts/`: 한글 글꼴과 각 글꼴의 라이선스
- `assets/visual/`: 이미지 번역용 목록과 메타데이터
- `tools/`: 추출, 검증 및 패치 제작에 사용한 보조 도구

저작권 보호와 저장소 용량을 위해 다음 파일은 포함하지 않습니다.

- 원본 또는 개조된 게임 ROM
- 선행 중국어 패치 및 그 적용 결과
- 게임에서 추출한 이미지·영상·음성·CPK 데이터
- 편집 중인 이미지와 재조립된 그래픽 바이너리
- 에뮬레이터 저장 데이터와 빌드 중간 파일

따라서 이 저장소만으로 게임 ROM을 얻거나 실행할 수 없습니다.

## 문제 제보

오탈자, 미번역 문장, 잘린 글자 또는 진행 불가 문제를 발견하면 Issues에
다음 정보를 함께 남겨 주세요.

- 문제가 발생한 장소와 진행 상황
- 문제 화면의 스크린샷
- 사용한 패치 버전
- 사용 환경(실기 또는 에뮬레이터 이름과 버전)

ROM 파일이나 저작권이 있는 원본 게임 데이터를 첨부하지 마세요.
